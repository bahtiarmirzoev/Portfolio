# Инструкция по запуску фронтенда

## Быстрый старт

### 1. Установите зависимости

```bash
cd frontend
npm install
```

### 2. Убедитесь, что бэкенд запущен

Бэкенд должен работать на `http://localhost:5076` (или другом порту, указанном в `launchSettings.json`).

### 3. Запустите фронтенд

```bash
npm run dev
```

Фронтенд будет доступен по адресу: **http://localhost:3000**

## Что было реализовано

### ✅ Аутентификация
- **Sign In** - Вход в систему
- **Sign Up** - Регистрация нового пользователя
- **Forgot Password** - Запрос кода OTP для сброса пароля
- **Reset Password** - Сброс пароля с использованием OTP кода
- **Sign Out** - Выход из системы
- **Token Refresh** - Автоматическое обновление токенов

### ✅ Дизайн
- Минималистичный дизайн с эффектом glassmorphism
- Плавные анимации при переходах (Framer Motion)
- Адаптивная верстка
- Современная цветовая схема с градиентами

### ✅ Функциональность
- Защищенные маршруты (требуют авторизации)
- Автоматическое добавление токена к запросам
- Обработка ошибок с красивыми уведомлениями
- Автоматическое обновление токенов при истечении

## Настройка API URL

Если ваш API работает на другом адресе, создайте файл `.env` в папке `frontend`:

```env
VITE_API_URL=http://your-api-url/api
```

## Изменения в бэкенде

В `Program.cs` добавлена поддержка CORS для работы с фронтендом:

```csharp
builder.Services.AddCors(options =>
{
    options.AddPolicy("AllowFrontend", policy =>
    {
        policy.WithOrigins("http://localhost:3000", "http://localhost:5173")
              .AllowAnyHeader()
              .AllowAnyMethod()
              .AllowCredentials();
    });
});
```
